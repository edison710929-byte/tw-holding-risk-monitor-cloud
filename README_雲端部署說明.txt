台股持股警訊監控器｜雲端版 v3 自動帶出股票名稱版

用途：
買進股票後，盤中或盤後監控是否出現重大警訊，輔助判斷續抱、留意、觀察/減碼或賣出警訊。

v3 更新重點：
1. 新增持股時，只需要輸入股票代號。
2. 股票名稱會依股票代號自動帶出。
3. 名稱來源優先抓公開上市/上櫃清單；抓不到時使用內建常見股票名稱備援。
4. 持股清單表格新增「自動補齊名稱」功能。
5. 仍保留買進價、股數、停損價、買進分數、買進理由等欄位。

部署方式：
1. 解壓縮本 ZIP。
2. 將資料夾內全部檔案上傳到 GitHub Repository。
3. 到 Streamlit Community Cloud 建立或更新 App。
4. Main file path 填 app.py。
5. 更新後如未自動重新部署，請在 Streamlit 按 Reboot / Rerun。

主要檔案：
- app.py：主程式
- requirements.txt：雲端套件清單
- 持股清單範例.csv：範例格式，v3 已不需要上傳即可使用

提醒：
本工具依公開行情與技術指標計算，資料可能延遲或中斷；實際買賣前請以券商 APP 報價與委買委賣確認。
