台股持股警訊監控器｜雲端版 v4 持股刪除／已賣出版

用途
----
買進股票後，依盤中量價與盤後技術指標監控是否出現重大警訊，輔助判斷續抱、留意、觀察／減碼、賣出警訊或重大警訊。

v4 新增功能
------------
1. 持股狀態管理：監控中／已賣出。
2. 標記已賣出／停止監控：輸入賣出日期、賣出價、賣出原因，系統保留交易紀錄並停止監控。
3. 刪除持股：用於輸入錯誤或不想保留紀錄的持股。
4. 已賣出紀錄區：可查看買進價、賣出價、實現損益%、賣出原因。
5. 已賣出的股票不會進入警訊監控。

部署方式
--------
1. 解壓縮 ZIP。
2. 將資料夾內的 app.py、requirements.txt 與其他檔案上傳到你的 GitHub Repository。
3. Streamlit Community Cloud 的 Main file path 填：app.py。
4. Commit 後等待 Streamlit 自動重新部署。
5. 若沒有更新，可到 Streamlit 按 Reboot 或 Rerun。

使用流程
--------
1. 進入「持股輸入 / 監控」。
2. 輸入股票代號、買進價、股數、停損價、買進理由。
3. 股票名稱會嘗試自動帶出。
4. 按「加入持股清單」。
5. 按「儲存並進入監控器」。
6. 按「開始檢查持股警訊」。

賣出後怎麼處理
--------------
正常賣出：
- 到「持股操作」選擇股票。
- 選「標記已賣出／停止監控」。
- 輸入賣出日期、賣出價、賣出原因。
- 按確認後，該股票會保留在已賣出紀錄，但不再監控。

輸入錯誤：
- 到「持股操作」選擇股票。
- 選「刪除持股（不保留紀錄）」。
- 勾選確認後刪除。

提醒
----
本工具依公開行情與技術指標計算，資料可能延遲、中斷或與券商報價不同。
實際買賣前，請再用券商 APP 確認即時價格、成交量與委買委賣。
此工具不是投資建議，也不是自動下單系統。
