台股持股警訊監控器｜雲端版 v5 瀏覽器本機儲存版

用途
----
買進股票後，依盤中量價與盤後技術指標監控是否出現重大警訊，輔助判斷續抱、留意、觀察／減碼、賣出警訊或重大警訊。

v5 新增功能
------------
1. 瀏覽器本機儲存：持股資料會自動存到目前瀏覽器的 localStorage。
2. 重新開啟自動載入：同一手機／同一瀏覽器／同一網址再次開啟時，會自動帶回上次持股資料。
3. 保留 v4 的標記已賣出／停止監控、刪除持股與已賣出紀錄。
4. 備份 / 還原：可下載持股備份 JSON，也可匯入備份還原。
5. 不需要 Excel 或 CSV 上傳持股資料。

重要限制
--------
1. 本機儲存只存在目前瀏覽器內，不會同步到其他手機、電腦或其他瀏覽器。
2. 若你清除 Safari / Chrome 網站資料，或更換裝置，持股資料可能消失。
3. 建議定期使用「下載持股備份 JSON」保存一份備份。
4. 若 Streamlit 雲端重新部署，通常不會影響瀏覽器本機資料；但若換網址，可能視為不同網站而讀不到舊資料。

部署方式
--------
1. 解壓縮 ZIP。
2. 將資料夾內的 app.py、requirements.txt 與其他檔案上傳到你的 GitHub Repository。
3. Streamlit Community Cloud 的 Main file path 填：app.py。
4. Commit 後等待 Streamlit 自動重新部署。
5. 若沒有更新，可到 Streamlit 按 Reboot 或 Rerun。

使用流程
--------
1. 進入「持股輸入 / 監控」。
2. 輸入股票代號與買進價等資料，股票名稱會嘗試自動帶出。
3. 按「加入持股清單」。
4. 系統會自動把資料存到目前瀏覽器。
5. 下次重新打開同一網址時，資料會自動載入。
6. 按「儲存並進入監控器」，再按「開始檢查持股警訊」。

賣出後怎麼處理
--------------
正常賣出：
- 到「持股操作」選擇股票。
- 選「標記已賣出／停止監控」。
- 輸入賣出日期、賣出價、賣出原因。
- 按確認後，該股票會保留在已賣出紀錄，但不再監控。

輸入錯誤：
- 到「持股操作」選擇股票。
- 選「刪除持股（不保留紀錄）」。
- 勾選確認後刪除。

提醒
----
本工具依公開行情與技術指標計算，資料可能延遲、中斷或與券商報價不同。
實際買賣前，請再用券商 APP 確認即時價格、成交量與委買委賣。
此工具不是投資建議，也不是自動下單系統。
