台股持股警訊監控器｜雲端版 v1

用途：
買進股票後，依盤中量價與盤後技術指標監控重大警訊，輔助判斷續抱、留意、觀察、減碼或賣出警訊。

主要功能：
1. 手動輸入持股資料。
2. 上傳 CSV / Excel 持股清單。
3. 自動抓取台股日線資料。
4. 計算盤中風險與盤後技術風險。
5. 顯示總風險分數與建議動作。
6. 顯示重大警訊與一般警訊。
7. 匯出本次監控結果 CSV。

部署方式：
1. 將本資料夾內全部檔案上傳到新的 GitHub Repository。
2. 到 Streamlit Community Cloud 建立新 App。
3. Repository 選你的新專案。
4. Branch 選 main。
5. Main file path 填 app.py。
6. 按 Deploy。

建議不要蓋掉原本選股掃描器：
請另開 GitHub 專案，例如：
tw-holding-risk-monitor-cloud

風險分數說明：
0～30：續抱觀察，條件尚未明顯破壞。
31～50：留意，短線有轉弱跡象。
51～70：觀察／減碼，警訊增加。
71～85：賣出警訊，原買進理由可能失效。
86～100：重大警訊，優先處理。

注意事項：
1. 此工具是技術面快篩與風險提示，不是下單建議。
2. Yahoo Finance / 公開行情資料可能延遲或中斷。
3. 實際交易前請以券商 APP 最新報價與委買委賣確認。
4. Streamlit 雲端版不會永久保存你的持股清單，建議使用 CSV 下載與上傳管理持股。
